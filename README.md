# 🛡️ Dashboard de Desconto Máximo Seguro

### 💡 Problema
Empresa concedia até 50% de desconto sem saber se tinha lucro.

### ✅ Solução
Dashboard Power BI com What-If Parameter + RLS que calcula o Lucro Real na hora.

### 📊 Resultados
- Carteira analisada: R$ 2M
- Economia estimada: R$ 85k/mês
- Trava de segurança: Bloqueio acima de 30% (RLS)

### 🛠️ Tecnologias
Power BI | DAX | What-If | RLS | Python | Git
